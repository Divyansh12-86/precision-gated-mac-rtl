# data/

This directory holds ECG signal data used by the Python golden model and RTL testbenches.

## mitbih/ — MIT-BIH Arrhythmia Database (gitignored)

Raw MIT-BIH records are **not committed** to this repo (large binary files, freely re-downloadable).

### Download via wfdb (recommended)

```bash
pip install wfdb
python - <<'EOF'
import wfdb
import os

os.makedirs("data/mitbih", exist_ok=True)

# Download records used in simulation (360 Hz, MLII lead)
for record in ["100", "101", "103", "105"]:
    wfdb.dl_database("mitdb", dl_dir="data/mitbih", records=[record])
    print(f"Downloaded record {record}")
EOF
```

### Manual download (alternative)

Records are available at: https://physionet.org/content/mitdb/1.0.0/

Download `.dat`, `.hea`, and `.atr` files for the records above and place them in `data/mitbih/`.

## test_vectors/ — RTL test vectors (committed)

Fixed-point input/output pairs exported by the Python golden model for bit-exact RTL verification.
These are small text/hex files and are committed to the repo.

Format (generated by `sim/golden_model.py`):
- `test_vectors/tv_inputs.hex` — quantized input samples (Q1.15, hex)
- `test_vectors/tv_outputs_full.hex` — expected outputs, full-precision MAC
- `test_vectors/tv_outputs_gated.hex` — expected outputs, approximate/gated MAC
- `test_vectors/tv_gate_flags.hex` — QRS gate control signal (1 = full, 0 = approx)
